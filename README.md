# Foliant

Фолиант — это веб-приложение для обмена книгами между пользователями. Сервис позволяет найти нужную книгу, договориться о встрече с владельцем и взять её почитать, а также поделиться своими книгами с другими.

## Назначение приложения
Платформа решает проблему поиска книг и организации их обмена. Пользователи могут создавать каталог своих книг, искать интересующие их экземпляры, бронировать их на определённый срок и отмечать возврат. Приложение помогает книгам находить новых читателей, а людям — экономить на покупке и находить единомышленников.

## Основные пользовательские сценарии
1. Регистрация и вход: Пользователь создаёт аккаунт или входит в существующий.
2. Добавление книги: Пользователь добавляет свою книгу в общий каталог (указывает название, автора, описание, место выдачи).
3. Поиск и фильтрация: Пользователь ищет книги по автору, названию или статусу (доступна/забронирована).
4. Бронирование: Пользователь находит книгу и отправляет запрос на бронирование.
5. Управление бронями: Пользователь видит список книг, которые он взял, и может отметить их возврат.
6. Просмотр своих книг: Пользователь может редактировать или удалять книги, которые он добавил в каталог.

## Экраны приложения (MVP)
На данном этапе реализованы следующие экраны:
* Каталог (Главная) — сетка карточек книг с поиском и фильтрами.
* Карточка книги — подробная информация о книге, кнопка «Забронировать», данные владельца.
* Мои книги — список книг текущего пользователя с кнопками редактирования и удаления.
* Мои брони — список забронированных книг с кнопкой «Вернуть».
* Вход / Регистрация — формы авторизации (пока без реальной отправки на сервер).

## Стек технологий (Frontend)
* React (библиотека для построения интерфейсов)
* TypeScript (типизация)
* Vite (сборщик)
* React Router DOM (клиентская маршрутизация)
* MUI (Material UI) (библиотека UI-компонентов)
